# 🚗 Rentt-Wheels Server

## About

Rentt-Wheels Server is the backend API for the **Rentt-Wheels** car rental platform. Built with **Node.js**, **Express.js**, and **MongoDB**, it provides secure and scalable REST APIs for managing users, vehicles, bookings, and authentication. The backend is designed for efficient data handling, high performance, and reliable system management.

---

## ✨ Features

- Secure RESTful API
- User authentication and authorization
- Vehicle management
- Booking management
- User profile management
- CRUD operations
- MongoDB database integration
- Scalable and maintainable backend architecture

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/GMRedoan/rent-wheels-server.git
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file and add:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```

### Run the server

```bash
npm run start
```

or

```bash
npm run dev
```
